# Agent instructions (kit repository)

This repository **is** the Research Agent Kit. A researcher may also use a *copy* of this folder as their project.

If they say **Start the project** or **Initiate**, use `skills/start-research-project/SKILL.md` and `policies/how-to-talk.md`. This folder is the kit: create a **new research folder** next to it (default **paper-1**, numbered `01-data` …). Do not require Python or R.

- Builders follow `SPEC.md` (frozen v0.1).
- Researchers start from `START.md` and `README.md`.
- Do not migrate live papers in v0.1.
- Do not widen scope into `BACKLOG.md` items without a new version.
