# Contributions

Inbox for collaborators, their assistants, leftover Google Doc comments, journal points, and AI manuscript review.

A contribution is a **proposal** (an open issue). It must not edit `RESEARCH_CONTEXT.md`, `ANALYSIS_PLAN.md`, accepted decision notes, or approved results.

**Do not** file one contribution per small wording change. Those are suggestions on the Google Docs review copy. Accept them there, then **Sync the review copy** into the manuscript.

Path: remark or open comment → this folder → the lead researcher reviews → then, if accepted, the canonical record is updated.

Use `template.md`. Name files `C-001-short-title.md`. If the issue came from a Doc comment, set `external_id` so a later ingest does not duplicate it.
