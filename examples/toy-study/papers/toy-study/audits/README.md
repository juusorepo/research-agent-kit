# Audit reports

Records of checks on the research chain (analysis plan → code → output → manuscript → claims).

These files are **history**, not current scientific authority. The analysis plan, accepted research decision notes, and approved result files still win.

The saved file is the report. Remaining work from a check belongs on the task list. The next chat is assigned by naming a task (for example **Do T-004**), not by pasting this file as a prompt.

Assistants must **not** load this folder by default. Do not treat an old report as agreeing an analysis or approving a result.
