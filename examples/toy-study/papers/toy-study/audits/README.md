# Audit reports

Records of checks: the research chain (analysis plan → code → output → manuscript → claims), and APA presentation of the rendered Word/PDF when they asked for that. A research-chain report keeps two statuses (numbers; claims). An APA presentation report keeps four (render; tables; figures; manuscript frame). Do not read one overall pass from either file.

These files are **history**, not current scientific authority. The analysis plan, accepted research decision notes, and approved result files still win.

The saved file is the report. If anything needs work, one row on the task list points at it. The next chat is assigned by naming a task (for example **Do T-004**), not by pasting this file as a prompt.

Assistants must **not** load this folder by default. Do not treat an old report as agreeing an analysis or approving a result.
