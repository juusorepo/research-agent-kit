# Start here

**Status: early development / v0.x.** APIs, structures, and conventions are expected to change.

You do **not** need Python or R to begin.

1. Copy this repository (clone or download ZIP) into a folder you own.
2. Open that folder with an AI assistant (Cursor, Claude, or another tool that can read the folder).
3. Say: **Start the project** (or **Initiate**).

The assistant will ask a few questions, including **your name** as lead researcher, then create the paper folders. Defaults are Quarto, R, and `papers/<name>/…`. You can change those answers.

After that, fill the project overview. The analysis plan may start empty.

Python is only for kit *tests* (`pytest`). Optional `scripts/install.py` is a shortcut if you already have Python — it is not required.
