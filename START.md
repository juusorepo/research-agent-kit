# Start here

Early development. You do not need Python or R.

An empty folder has no instructions. You tell the assistant **where** the kit is.

## Start a paper

1. Create an empty folder for the paper. Open it with your AI assistant.
2. Paste this (add your name):

```
Start the project from https://github.com/juusorepo/research-agent-kit
My name is
```

3. Copy your plan or draft into `06-docs/` and `manuscript/`.
4. Say **Understand the project**.

The assistant fetches that public kit, copies how-to files into **this** folder (not tests or builder files), and creates `01-data`, `02-scripts`, `manuscript`, and the rest. Then it drafts the overview and analysis plan from what you copied; you accept; it writes them.

A second paper: another empty folder, same paste.

If you only send your name: Quarto, R, no individual-level data, no AI-use log. The folder keeps the name you gave it.

## Later

In the paper, say **Update the copied instructions from https://github.com/juusorepo/research-agent-kit**. Your overview, plan, data, scripts, and manuscript stay.

## If you already have this kit folder open

Say **Start the project**. The assistant creates a **new** paper folder next to the kit. Day to day, open only that paper.
