# Claude Code pointer (optional)

This file stays in the kit (`adapters/claude/`). Papers use `AGENTS.md`.

Claude Code reads `CLAUDE.md`, not `AGENTS.md`. If you use Claude Code in a paper, add a one-line `CLAUDE.md` at the paper root:

```
@AGENTS.md
```

Do not paste kit rules into it. The kit does not generate this file.

If you use Claude Code in this kit folder, follow `AGENTS.md`.
