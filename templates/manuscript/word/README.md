# Word manuscript (reserved)

v0.1 records `manuscript_format: word` in `layout.yml` and creates this folder. A Word template is not shipped yet. Do not invent a Word toolchain.

Until a later kit version: keep the canonical draft as Markdown or Quarto, or place a `.docx` here yourself. Review copies emailed to co-authors remain snapshots if this folder is the source of truth you chose.
