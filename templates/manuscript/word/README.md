# Word manuscript (reserved)

v0.1 records `manuscript_format: word` in `layout.yml` and creates this folder. A Word template is not shipped yet. Do not invent a Word toolchain.

Until a later kit version: keep the canonical draft as Markdown or Quarto, or place a `.docx` here yourself. Co-author **comment ingest** for Word is not shipped. Prefer a Google Docs review copy (see **Prepare a review copy**).
